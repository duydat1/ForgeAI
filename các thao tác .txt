    - Ta quy định V1 chỉ phân tích 3 đuôi .cpp .h .hpp 
    - Đọc file xem có bao nhiêu dòng , mỗi 1 dòng là loại j , mỗi 1 loại có bao nhiêu dòng 
    - Chia nhỏ file analyzer.cpp thành file_analyzer.cpp và file_analyzer.h (.h không chứa cách làm, nó chỉ nói: “ForgeAI có một hàm tên analyzeFile, muốn dùng thì gọi nó.” )
        + Đưa hàm analyzeFile từ analyzer sang file_analyzer . 
        + Thêm vào đầu file analyzer   '''  #include "file_analyzer.h"  '''
